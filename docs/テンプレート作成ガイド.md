# テンプレート作成ガイド(Excelで帳票を作る人向け)

対象読者: Excelで帳票のテンプレート(`template.xlsx`)を作成・修正する担当者。
関連ドキュメント: `docs/帳票定義スキーマ.md`(差し込みセルの登録)、`docs/ライブラリの使い方.md`(プログラムからの呼び出し)

Utsushiは、Excelで作ったテンプレートの決まったセルに、プログラムから発行日・宛先住所・氏名・担当者などの文字列を
差し込んでPDFにする。Excelの見た目をできるだけそのまま再現するが、Excelの機能をすべて再現するわけではない。
本書は、テンプレートを作るときに守ると「Excelで見た通りのPDF」になり、差し込んだ値が欠けたり化けたりしないための
決まりをまとめたものである。

## 1. 最初に確認すること

| 確認項目 | 理由 |
|---|---|
| シート名が帳票定義(`definition.json`)の `sheetName` と一致している | 一致しないとエラーになる |
| 印刷範囲を設定している(「ページレイアウト」→「印刷範囲」) | 印刷範囲の外のセルはPDFに出ない。差し込みセルが範囲外(印刷タイトルの行・列の中は可)にあるとエラーになる。帳票定義の `printArea` で印刷範囲を上書きすることもできる |
| 用紙サイズ・向き・余白・拡大縮小(「次のページ数に合わせて印刷」を含む)を設定している | PDFのページサイズと配置はこの設定で決まる |
| Excelの「印刷プレビュー」で意図どおりに見える | Utsushiは印刷プレビューの見た目を再現の目標にしている |

## 2. フォント

- **日本語を入れるセルには日本語フォントを指定する**(ＭＳ Ｐゴシック、游ゴシック、メイリオ、BIZ UDPゴシックなど)。
  英字フォント(Arial、Calibri など)のセルに日本語を入れると、日本語の部分は同梱のBIZ UDPゴシックで描かれる。
  Excel はこの場合別のフォントで表示するため、文字の幅が変わり、折り返し位置などがExcelの見た目とずれることがある。
- **PDFを作るサーバーに、テンプレートで使うフォントがインストールされている必要がある。** 無い場合、既定の設定では
  変換がエラー(`FontNotAvailableException`)になる。新しいフォントを使うときは、システム担当者にサーバーへの
  導入を依頼する。BIZ UDPゴシックはライブラリに同梱しているため、どのサーバーでも使える。
- **TrueType形式のフォントを使う。** Windows標準の日本語フォント、BIZ UD、IPA系はTrueType形式である。
  Noto Sans CJK のようなOpenType(CFF)形式のフォントは、PDFの文字列検索がしにくい形式(Type 3)で出力され、ファイルも大きくなる。
  形式は拡張子では判別できない(.ttc や .otf にも両方がある)。分からない場合はシステム担当者に確認する。
- 太字・斜体・下線(一重・二重)・取り消し線・文字色は再現する。会計用の下線は、一重・二重の下線と同じ位置・長さで描く
  (Excelの会計用下線はやや低い位置に引かれるため、見た目が少し異なる)。
- 主要な日本語フォント(ＭＳ ゴシック/明朝系、游ゴシック/明朝、メイリオ、BIZ UD系、IPA系)は、日本語名(「ＭＳ Ｐゴシック」)のままでよい。
  英語名のフォントとしても探す。

### 人名・住所の外字と異体字

- 氏名・住所には、JIS第4水準の外の文字(「𠮷」など)や、異体字セレクタ付きの文字(戸籍系データの「葛」の異体など)が
  含まれることがある。セルのフォントにその字が無い場合、Utsushi は同梱のBIZ UDPゴシック、次にサーバーに
  インストールされたIPAmj明朝(人名用の文字を約6万字収録)から、その字だけを探して描く。
- どのフォントにも無い字は、豆腐(□)のまま出力せずエラーにする。外字が出る帳票を発行するサーバーには、IPAmj明朝の
  導入をシステム担当者に依頼する。
- IPAmj明朝は明朝体しか無いため、ゴシック体の宛名の中で外字だけが明朝体になる。これを避けたい場合は、同じ書風の
  外字フォントをシステム側で登録する(`docs/ライブラリの使い方.md`「日本語の人名・住所の文字」)。

## 3. 差し込みセルの作り方

差し込むセルは、帳票定義の `substitutionFields` にセル番地を登録する(`docs/帳票定義スキーマ.md`)。

| 差し込む値 | テンプレートでの設定 |
|---|---|
| 宛名・氏名・担当者など1行の値 | 想定する最長の文字数が入る列幅にする。長い値が来うる場合は「縮小して全体を表示する」を有効にする(帳票定義で `"overflow": "shrink"` を指定してもよい) |
| 住所・備考など複数行の値 | 「折り返して全体を表示する」を有効にし、**想定する最大行数ぶんの行の高さを確保する**。差し込んだ値が行の高さに収まらない場合、切れたまま発行されないようエラーになる |
| 金額 | 横位置を「右揃え」にする。置換キー・`SetText` で差し込む値は文字列として入るため、横位置が「標準」のままだと左揃えになる(`Excel2Pdf.SetValue` で数値として設定したセルは、「標準」でも Excel と同じく右揃えになる) |
| 日付・金額の表示形式 | テンプレートの「表示形式」(数値書式・日付書式)は、置換キー・`SetText` で差し込んだ文字列には効かない。その場合はプログラム側で `"2026年4月1日"`・`"¥1,000"` のように整形済みの文字列を渡す。プログラムが `Excel2Pdf.SetValue` で数値・日付を設定するセルには表示形式が効く(要件14)ので、そのセルには表示形式を設定しておく |
| 結合セル | 結合範囲の**左上のセル**の番地を登録する。それ以外の番地に差し込むとエラーになる |

- 差し込みセルを、印刷範囲の外・非表示の行や列・幅や高さが0の列や行に置かない(値が出ないため、エラーになる)。
- 差し込みセルの書式(フォント・罫線・塗りつぶし・配置)はテンプレートのものがそのまま使われる。
  一度も入力・書式設定をしていないセルに差し込むと、Excel と同じく、行全体・列全体に設定した書式(行番号・列見出しをクリックして
  設定したもの)、それも無ければブックの標準の書式(日本語版の新規ブックでは游ゴシック 11pt)で描かれる。
- 値も書式も無いセルを差し込み先にする場合は、そのセルに書式(罫線・フォントなど)を設定しておく。値か書式のあるセルの範囲
  (使用範囲)の外のセルを帳票定義に登録するとエラーになる。
- 差し込むセルを数式で参照しない(例: `=B3&" 様"`)。Utsushi は数式を再計算せず、テンプレートを保存したときの計算結果を
  そのまま出力するため、差し込んだ値が反映されない。
- 折り返しの位置は1文字単位で決まる。Excel の単語単位の折り返しや禁則処理(句読点を行頭に置かない)は行わないため、
  行数が1行ずれることがある。行の高さには1行ぶんの余裕を持たせる。
- 折り返しを有効にしていないセルに改行を含む値を差し込むと、改行は表示されず1行につながる。

## 4. 印刷の設定

Utsushi は Excel の印刷設定(「ページレイアウト」タブ・「ページ設定」ダイアログ)を読んでページを組み立てる。
次の設定は Excel と同じように効く。

| 設定 | Utsushi での扱い |
|---|---|
| 印刷タイトル(「タイトル行」「タイトル列」) | Excelと同じく、タイトルより後ろの行(列)から始まるページにだけ付く。表題・宛先の下にある表の見出し行をタイトル行にしてよい(1ページ目は見出し行がそのままの位置に出て、2ページ目以降の先頭に繰り返される)。印刷範囲より下(右)にある行(列)をタイトルにすると、どのページにも出ない(そこに差し込みセルを置くとエラーになる) |
| 「次のページ数に合わせて印刷」 | 指定のページ数に収まる最大の倍率(1%単位、10〜100%)を選ぶ。この設定のときは手動の改ページは無視される(Excelと同じ)。区切り位置によっては、合計の大きさから見積もった倍率より小さくなる |
| 手動の改ページ | 改ページを挿入した行(列)の手前で改ページする。その行(列)が非表示でも、次に印刷される行(列)の手前で改ページする |
| 「ページ中央」(水平・垂直) | 各ページの表(印刷タイトルを含む)を、余白の内側の中央に置く。表が余白の内側より大きいページでは動かさない |
| 「先頭ページ番号」 | ヘッダー/フッターのページ番号をその番号から数える。総ページ数(`&[総ページ数]`)は最後のページの番号になる。「奇数/偶数ページ別指定」は表示する番号の奇数・偶数で、「先頭ページのみ別指定」は1枚目のページで選ばれる |
| ヘッダー/フッターの `&[ページ番号]+1`・`&[ページ番号]-1` | ページ番号に足した(引いた)数を表示する |
| 行の高さ | 文字の大きさに合わせて自動で高くなった行も、Excelが保存した高さで印刷する。高さ0の行・幅0の列は印刷しない |

先頭ページ番号を指定したときの総ページ数と奇数・偶数の選び方、ページ中央に印刷タイトルを含めること、印刷範囲より下にある
タイトル行の扱いは、Excelの印刷結果との突き合わせをまだしていない。これらを使う帳票は、登録前にExcelの印刷プレビューと見比べる。

## 5. 再現できるもの・できないもの

### 再現する

- セルの値・フォント・罫線(線種・太さ・色、斜線を含む)・塗りつぶし・結合セル
- 横位置(左・中央・右)、縦位置(上・中央・下)、インデント、折り返し、縮小して全体を表示
- 印刷範囲(複数の印刷範囲を含む)、手動の改ページ、自動の改ページ、印刷タイトル(行・列の繰り返し)、ページの方向(行優先/列優先)
- 用紙サイズ・向き・余白・拡大縮小率・「次のページ数に合わせて印刷」・「ページ中央」(水平・垂直)
- ヘッダー/フッター(左・中央・右、ページ番号・総ページ数・日付・時刻・シート名・文字色、先頭ページ/奇数・偶数ページの別指定、
  「先頭ページ番号」、`&[ページ番号]+1` のような番号の足し引き、フォントのスタイル(太字・斜体))
- 行の高さ(自動調整された高さも含む。Excelが保存した高さをそのまま使う)。高さ0の行・幅0の列は、非表示と同じく印刷しない
- セルの表示形式(数値書式): 桁区切り・小数・パーセント・通貨(¥)・日付・時刻に加え、経過時間(`[h]:mm` など、24時間を超えて数える)
  と和暦(`ggge"年"m"月"d"日"` で「令和8年4月1日」、`ge.m.d` で「R8.4.1」など)。表示は日本語版Excelの組み込みの表示形式に合わせる。
  表示形式の色の指定(「負の数を赤で表示」の `[赤]`・`[Red]` など)も再現する。置換キー・`SetText` で差し込んだ値は文字列のため、この色にはならない(`Excel2Pdf.SetValue` で設定した数値には効く)
- 行全体・列全体に設定した書式(塗りつぶし・罫線・フォント)。値の無いセルにも Excel と同じく反映する(印刷範囲が非常に広く、行全体・列全体の書式で描く空のセルが20万か所を超える場合は、変換がエラーになる)
- 画像(PNG・JPEG・GIF・BMP。回転を含む)。会社ロゴなど
- 図形: 四角形・角丸四角形・楕円・三角形・矢印(上下左右・左右・上下)・星形(4・5・6・8点)・吹き出し(四角形・角丸四角形・
  楕円・雲形、線吹き出し1〜3(枠付き・枠なし・強調線付き・枠付きかつ強調線付き))・フローチャート記号(処理・判断・端子・データ・書類・定義済み処理・結合子)、図形内の文字、グループ化した図形、図形の左右・上下の反転
- 図形の色: 「標準の色」「その他の色」に加え、「テーマの色」(明るさを変えた色を含む)・透過、図形のスタイル(Excelで挿入したままの図形の色・枠線)
- 線: 直線、カギ線(折れ1〜2回)、曲線。線と線吹き出しの引き出し線の端の矢印(三角・鋭角・開いた矢印・丸・ひし形)
- セルの塗りつぶし(単色)

### 再現しない(テンプレートで使わない)

| Excelの機能 | Utsushi での扱い |
|---|---|
| 文字の方向・回転(縦書きを含む) | 横書きで出力される(エラーにならない) |
| 横位置「均等割り付け」「両端揃え」「繰り返し」 | 左揃えになる |
| 横位置「選択範囲内で中央」 | そのセルの中だけで中央揃えになる。中央に置きたい範囲はセルを結合する |
| 縦位置「均等割り付け」「両端揃え」 | 中央揃えになる |
| 条件付き書式 | 反映されない(条件を満たしても書式が変わらない) |
| セル内で一部の文字だけ書式を変える(リッチテキスト) | セル全体が1つの書式(セルの書式)で描かれる。テンプレートにもともと入力してある文字も同じ |
| 数式 | 再計算しない。テンプレートを保存したときの計算結果がそのまま出る |
| セルの塗りつぶしの網かけ(パターン) | 背景色の単色で近似する |
| セルの塗りつぶしのグラデーション | 塗りつぶしなし(透明)になる |
| はみ出し表示で隣のセルに値がある場合 | Excelは隣のセルの手前で切るが、Utsushi は重ねて描く。テンプレートに入力してある見出しなどの文字にも起きる。はみ出す可能性があるセルは「縮小して全体を表示する」にするか、列幅を広げる。重なる箇所はプログラムから確認できる(`docs/ライブラリの使い方.md`「文字の収まりの確認」)。なお、はみ出した文字は用紙の余白には描かれず、余白の手前で切れる。結合セルの文字は結合範囲の外へははみ出さない(Excelと同じ) |
| 数値がセル幅に収まらない場合の `####` 表示 | Excelは `####` と表示するが、Utsushi は数値をそのまま描く(はみ出す・切れる)。数値のセルは想定する最大の桁数が入る列幅にする。収まらない数値はプログラムから確認できる(`docs/ライブラリの使い方.md`「文字の収まりの確認」) |
| 和暦の「元年」 | 1年は「令和1年」のように「1」と表示する。「元年」と出したい場合は、その日付を整形済みの文字列で差し込む |
| 回転(90度など)した用紙サイズ(「A4 回転」など)と横向きの組み合わせ | Excelとの一致を確かめていない。通常の用紙サイズ(A4など)と「横」の組み合わせを使う |
| 45〜135度回転した画像 | 位置・大きさがExcelとずれることがある。回転させる画像(印影など)は小さい角度にとどめ、PDFで確認する |
| 最後の行(列)が非表示になっている結合セル | 外周の罫線の一部が出ないことがある。結合範囲に非表示の行・列を含めない |
| 複数行のヘッダー/フッター、ヘッダー/フッターの画像 | 改行は無視され1行になる。画像は出ない |
| グラフ、対応していない図形(自由曲線、星形7点・10点以上など)、外部参照 | 帳票定義の `unsupportedElements` の設定に従う。既定の `ignore` では**何も出力されず、エラーにもならない**。`error` にすると変換がエラーになる |
| EMF/WMF 形式の画像(図の貼り付けで作られることが多い) | 対応していない。既定の設定では**黙って出力されない**。PNG か JPEG で貼り付け直す |
| セルのコメント(メモ)・フォームコントロール | PDFには出ない。`unsupportedElements` が `error` の場合は変換がエラーになる |
| 改ページをまたぐ結合セル | 両方のページに同じ文字が出る。結合セルは1ページに収める |
| 改ページをまたぐ画像・図形 | 左上が属するページにだけ出る。線吹き出しの引き出し線が次のページや印刷範囲の外へ伸びる場合も、本体の左上が属するページにまとめて描かれる |
| 画像の反転 | 画像そのものは鏡像にならない(グループ化した図形の中の画像は、位置だけが反転に合わせて動く) |
| 図形の塗りつぶしのうち、スタイルが指すグラデーション・テクスチャ・模様 | スタイルの色の単色で近似する |

## 6. 登録前のチェックリスト

- [ ] 印刷範囲・用紙・余白・拡大縮小を設定し、Excelの印刷プレビューで確認した
- [ ] 差し込みセルが印刷範囲の中にあり、非表示の行・列にない
- [ ] 日本語を入れるセルに日本語フォントを指定した
- [ ] 使ったフォントがPDFを作るサーバーにある(または同梱のBIZ UDPゴシックを使った)
- [ ] 住所など複数行のセルは折り返しを有効にし、最大行数ぶんの高さを確保した
- [ ] 金額のセルは右揃えにした
- [ ] 結合セルに差し込む場合、左上のセルの番地を帳票定義に登録した
- [ ] 「再現しない」機能(縦書き・均等割り付け・条件付き書式・EMF画像・グラフなど)を使っていない
- [ ] 差し込むセルを数式で参照していない
- [ ] 狭い列の見出し・一覧の長い名称が、隣の値と重ならないことをPDFで確かめた(開発者に文字の収まりの確認(`CheckFit`)を依頼すると、重なる箇所を一覧にできる)
- [ ] 想定する最長の値・最大行数の値・外字を含む値でPDFを作り、Excelの印刷プレビューと見比べた
- [ ] 帳票定義なしのCLI(`--report` の省略)で見た目を確かめた場合も、登録後に帳票定義(`unsupportedElements: "error"`)で変換し直した
  (帳票定義なしの変換は対応していない要素を黙って無視するため、登録後にエラーになる要素を見落とす)

登録の手順(テンプレートと帳票定義の配置、回帰テストの追加)は `.kiro/steering/structure.md`「帳票の追加手順」を参照。
